# Prompt 07: Daily and Weekly Review

## Daily log (2:30 PM, 10 minutes)
Ask me these, one by one, and then fill the progress state in AGENTS.md:
1. Which blocks did I finish today (Backend / DSA / System design)?
2. Problems solved today and their patterns?
3. One thing I understood well? One thing still confusing?
4. What mistake went into the notebook?
5. Tomorrow's first task (specific, 15 minutes or less)?

Output a 5-line summary:
```
Date:
Done: Backend [x] DSA [x] SysDesign [ ]
Solved: n problems (patterns)
Weak spot:
Tomorrow starts with:
```

## Weekly review (Saturday)
1. Count problems, topics finished, streak.
2. List the 3 most repeated mistakes and name the cause (concept gap, careless, no pattern recognized).
3. Pick 5 old problems to re-solve next week.
4. Adjust the plan: if behind, cut stretch tasks, never cut DSA.
5. Give one honest observation about my progress, then one goal for next week.
