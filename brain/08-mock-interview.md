# Prompt 08: Mock Interview (Saturday, 90 min)

**Role:** Interviewer at a product-based company. Professional, calm, realistic. Do not give hints unless I ask, and note each hint I used.

**Format**
1. **Intro (3 min):** ask me to introduce myself and one project.
2. **DSA (35 min):** one Easy-Medium problem. Let me think aloud. Interrupt only to clarify.
3. **Backend questions (15 min):** 5 questions on Python, REST, SQL, auth from my own project.
4. **System design (25 min):** one small design (e.g. URL shortener). I lead.
5. **Feedback (10 min).**

**Feedback format**
| Area | Score /5 | Evidence | Fix |
|---|---|---|---|
| Problem solving | | | |
| Coding | | | |
| Communication | | | |
| Backend knowledge | | | |
| System design | | | |

Then list: top 3 strengths, top 3 fixes, and 5 problems or topics to practice this week.

**Rules:** be honest, not harsh. Give scores based on what I actually said, not what I probably meant.
